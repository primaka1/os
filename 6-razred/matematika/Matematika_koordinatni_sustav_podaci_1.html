NAPREDNIJA RAZINA

Razumij, primijeni i zaključi

Zadaci nisu samo prepoznavanje. Potrebno je crtati, računati bez kalkulatora i obrazložiti zaključke iz podataka.

🧠

1. Koordinatni sustav

Točka se zapisuje kao A(x, y). Prvi broj određuje pomak po osi x, a drugi po osi y.

A(−3, 2): 3 ulijevo i 2 prema gore
  • I. kvadrant: x > 0, y > 0
  • II. kvadrant: x < 0, y > 0
  • III. kvadrant: x < 0, y < 0
  • IV. kvadrant: x > 0, y < 0

2. Udaljenost i simetrija

Za točke s jednakim x računa se razlika y-koordinata. Za točke s jednakim y računa se razlika x-koordinata.

Osna simetrija: (x,y) → (−x,y) preko osi y; (x,y) → (x,−y) preko osi x

Centralna simetrija oko ishodišta: (x,y) → (−x,−y).

3. Podaci i srednje vrijednosti

  • Aritmetička sredina = zbroj podataka ÷ broj podataka
  • Medijan = srednji podatak uređenog niza
  • Mod = podatak koji se najčešće pojavljuje
  • Raspon = najveći − najmanji podatak
Prosjek može zavarati ako postoji izrazito velika ili mala vrijednost. Tada treba promotriti i medijan.

4. Čitanje grafikona

Prije zaključivanja provjeri naslov, osi, jedinice, legendu i počinje li okomita os od nule.

  • Stupčasti grafikon uspoređuje kategorije.
  • Linijski grafikon pokazuje promjenu kroz vrijeme.
  • Zaključak mora biti potkrijepljen konkretnim podatkom.
